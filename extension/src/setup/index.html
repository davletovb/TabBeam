Connect the companion

TabBeam uses the same Seatline installation as your other authorized apps. Connect it, then follow your provider's own sign-in flow.

  1. Install the macOS companion

    Install Seatline once using the shared companion setup. This development build provides a native binary; a signed macOS installer is not available yet. Installers from the TabBeam releases page register the older com.tabbeam.host and do not work with this extension build, which connects to com.seatline.host. If you already use Seatline with another app, authorize TabBeam below.

  2. Install the Windows companion

    Install Seatline once using the shared companion setup. This development build provides a native binary; a signed Windows installer is not available yet. Installers from the TabBeam releases page register the older com.tabbeam.host and do not work with this extension build, which connects to com.seatline.host. If you already use Seatline with another app, authorize TabBeam below.

  3. Choose a provider

    Seatline is installed once and shared by TabBeam, Conclave, and other authorized apps.

    Choose Codex or Claude above. The status beside each provider tells you whether its tool is found and signed in.

  4. Install and sign in to your provider

    If its tool is missing, follow the Codex CLI guide or Claude Code guide. Sign in through that tool. TabBeam does not collect provider credentials.

  5. Reopen TabBeam

    Open the popup again. The selected provider should read ready. If it does not, use the status above to fix the remaining setup step.

Shared companion setup

Install Seatline once, then follow the TabBeam integration setup for this development build.

seatline-companion install

Authorize this extension. --allow-provider-default lets TabBeam's plain questions, which send no page context, use your provider's own tool settings; without it those questions are refused.

seatline-companion authorize tabbeam codex,claude,gemini,grok chrome-extension://EXTENSION_ID/ --cache-title=TabBeam --allow-provider-default

Register TabBeam's built native integration at its permanent location:

seatline-companion register-native tabbeam /absolute/path/to/tabbeam-host

Use the full path to tabbeam-host.exe on Windows. Reopen TabBeam after authorization.

Remove TabBeam in Chrome. To remove its Seatline access, run seatline-companion revoke tabbeam. Your other apps keep using Seatline, and provider credentials stay with the provider tool.
