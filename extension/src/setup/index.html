Pervue

Set up the companion app

Pervue packaging is not finished yet. Development builds still require the native companion to be built and registered manually.

  1. Build the native host from the repository with cargo build --manifest-path native/Cargo.toml.
  2. Find this extension's ID on chrome://extensions.
  3. Run pervue-host --print-manifest <extension-id> and register the printed manifest in Chrome's Native Messaging host location for your operating system.
  4. Install and sign in to Codex using its supported authentication flow.
  5. Reopen Pervue. The provider status line should report when Codex is ready.

These steps are for development only. Milestone G replaces them with an installable companion package.
