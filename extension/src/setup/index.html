Connect the companion

Packaging isn't finished yet, so development builds register the companion by hand. It takes about five minutes.

  1. Build the companion

    From a checkout of the repository, build the native host.

    cargo build --manifest-path native/Cargo.toml

  2. Find this extension's ID

    Open chrome://extensions, turn on Developer mode, and copy the ID shown on the Pervue card.

  3. Register the companion with Chrome

    Print the Native Messaging manifest for your extension ID, then save it in Chrome's Native Messaging host location for your operating system.

    pervue-host --print-manifest <extension-id>

  4. Install and sign in to Codex

    Install Codex and sign in with its supported authentication flow. Pervue never sees your credentials.

  5. Reopen Pervue

    Open the popup again. The status under the Pervue name turns green and reads Codex is ready once everything is connected.

These steps are for development only. Milestone G replaces them with an installable companion package.
