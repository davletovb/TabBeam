Connect the companion

Pervue checks the companion and each provider above. Connect a companion compatible with this extension, then follow your provider's own sign-in flow.

  1. Install the macOS companion

    Download the Pervue companion package from the Pervue releases and open it in Finder. The installer registers the host with Chrome automatically. If the popup says the companion needs an update, install the matching newer package.

  2. Install the Windows companion

    Download the Pervue companion installer from the Pervue releases and open it normally. It installs for your Windows account and registers the host with Chrome automatically. If the popup says the companion needs an update, install the matching newer package.

  3. Choose a provider

    Choose Codex or Claude above. The status beside each provider tells you whether its tool is found and signed in.

  4. Install and sign in to your provider

    If its tool is missing, follow the Codex CLI guide or Claude Code guide. Sign in through that tool. Pervue does not collect provider credentials.

  5. Reopen Pervue

    Open the popup again. The selected provider should read ready. If it does not, use the status above to fix the remaining setup step.

Development build or Linux

For Linux or an unpacked extension with its own ID, build the native host from a checkout and register it for the exact ID shown on Pervue's card at chrome://extensions. Windows development registration can use the HKCU path described below.

cargo build --manifest-path native/Cargo.toml

Print the manifest with the built host, using the extension ID from Chrome:

native/target/debug/pervue-host --print-manifest <extension-id>

Save the resulting JSON as com.pervue.host.json in Chrome's NativeMessagingHosts directory: ~/.config/google-chrome/NativeMessagingHosts on Linux or ~/Library/Application Support/Google/Chrome/NativeMessagingHosts on macOS. On Windows, save it at a stable path and set the default value of HKCU\Software\Google\Chrome\NativeMessagingHosts\com.pervue.host to that full path. The manifest's host path must be absolute.

To remove the companion on macOS, open Applications → Uninstall Pervue. Remove the extension separately in Chrome. Provider credentials stay with the provider tool.

To remove the companion on Windows, open Settings → Apps → Installed apps → Pervue Companion → Uninstall. Remove the extension separately in Chrome. Provider credentials stay with the provider tool.
